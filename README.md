# OSTdrivegroupe — сайт

Статический сайт компании OSTdrivegroupe: поставки расходников для кузовного ремонта (OST Supply) и инженерные проекты (OST Lab).

Чистый HTML/CSS/JS, без сборки — достаточно открыть `index.html`.

## Страницы
- `index.html` — главная (два экрана)
- `catalog.html` — расходники
- `workshops.html` — автомастерским
- `lab.html` — инженерные проекты
- `investors.html` — инвесторам
- `contacts.html` — контакты
